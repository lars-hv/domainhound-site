How Domain Hound does it

The server runs on your machine. It sends the names you ask about to public sources: registries, price lists, app stores and the USPTO. It has 4 tools. The check_domains tool takes up to 20 names per call.

FAQ

Do I need an API key?
No. Domain checks and list prices run without a registrar key.
How can I check the connection?
Ask your assistant to use check_domains on example.com. Look for the tool call and a dated result.
Can my agent buy a domain?
You hold the leash. Direct buying requires your own Spaceship account and your permission. The default quote cap is $30. If an order’s status is unclear, the agent won’t retry it.
