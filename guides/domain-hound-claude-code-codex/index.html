How Domain Hound does it

Install Node.js 20 or later. Run the command for your client in your terminal, then reopen the client. The server runs on your machine and sends the name to public sources.

For Claude Code

claude mcp add domain-hound -- npx -y domain-hound

For Codex

codex mcp add domain-hound -- npx -y domain-hound

FAQ

Do I need an API key?
The default domain and list price checks run without a registrar key.
How can I check the connection?
Ask your assistant to use check_domains on example.com. Look for the tool call and a dated result.
Does it need a registrar login to buy?
Domain Hound never buys. Open the registrar yourself and check the final price.
