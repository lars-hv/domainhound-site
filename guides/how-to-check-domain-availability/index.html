How Domain Hound does it

Give Domain Hound a full name such as example.com. It looks for a registry record using RDAP or WHOIS. If the registry stays silent, it can use DNS for a clue. Ask for a shop check before you pay.

FAQ

What if the site never loads?
The owner may use the domain for email, park it or leave it empty.
Why does the shop want more?
The registry can set a premium price for an unregistered name. A price set by an existing owner is a resale price.
When is the name mine?
After the registrar accepts the registration. A lookup does not hold it for you.
