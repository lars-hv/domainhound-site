How Domain Hound does it

Ask for candidates. Say each one aloud and write it from memory. Then screen the keepers for the exact domain, similar marks and apps with the same name.

FAQ

How short should the name be?
Short enough to say over the phone once. A familiar word can beat a name you invented.
Can I just leave out a vowel?
Try it on someone who has never seen the word. If you spell it out every time, try another spelling.
What if my favorite name is available?
Search it first. An empty registry record says nothing about the brands your buyers already know.
